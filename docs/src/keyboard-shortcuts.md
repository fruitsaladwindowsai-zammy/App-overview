# Keybindings & Shortcuts

## Global Triggers

| Shortcut / Input | Action |
|---|---|
| **4-Finger Swipe Up** | Toggle Winscroller 2d Appview (suppresses Windows Task View) |
| **4-Finger Swipe Down** | Dismiss Winscroller 2d Appview (when open) |
| `Alt + Space` | Global toggle hotkey |
| **Left-Click Tray Icon** | Toggle Winscroller 2d Appview |
| **Right-Click Tray Icon** | Open context menu (Open, Edit Config, Reload Apps, Exit) |

## In-Overview Navigation

| Key / Action | Effect |
|---|---|
| **Type letters** | Filter applications instantly with Alfred-style fuzzy search |
| `Backspace` | Remove last search character |
| `Esc` | Clear active search query, or dismiss launcher if search is empty |
| `Enter` | Launch selected app and smoothly dismiss |
| `ArrowRight` / `ArrowLeft` | Move selection horizontally with automatic page rollover |
| `ArrowDown` / `ArrowUp` | Move selection vertically within page |
| `PageDown` / `PageUp` | Spring to next / previous page |
| **2-Finger Horizontal Swipe** | Continuous sub-pixel page sliding with fling momentum |
| **Drag Down (`> 55px`)** | Dismiss overview |
| **Click Pagination Pill** | Spring directly to clicked page |
| **Click Empty Wallpaper** | Dismiss overview |
