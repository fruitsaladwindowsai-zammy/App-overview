# Contributing

Contributions of all kinds — gesture refinements, icon extraction improvements, UI polish, bug reports, and documentation — are warmly welcomed!

## Quick Checklist Before Opening a PR
1. Run `cargo fmt -- --check`
2. Run `cargo clippy --all-targets`
3. Run `cargo test`
4. Run `cargo check --release --tests`
5. Update relevant documentation (`README.md`, `KEYBINDINGS.md`, `CONFIGURATION.md`, `docs/src/`, `CHANGELOG.md`)

See the root [CONTRIBUTING.md](https://github.com/fruitsaladwindowsai-zammy/App-overview/blob/master/CONTRIBUTING.md) and [CODE_OF_CONDUCT.md](https://github.com/fruitsaladwindowsai-zammy/App-overview/blob/master/CODE_OF_CONDUCT.md) for complete guidelines.
