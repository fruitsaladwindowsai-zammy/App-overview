# Keyboard Shortcuts & Controls

## Global Triggers
| Trigger | Action |
|---|---|
| **4-Finger Swipe Up** | Toggle overview (stops Windows Task View) |
| **4-Finger Swipe Down** | Dismiss overview (suppresses Show Desktop while open) |
| `Alt + Space` | Toggle overview globally |
| **Left-Click Tray Icon** | Toggle overview |
| **Right-Click Tray Icon** | Context menu (Open, Edit Config, Reload Apps, Exit) |

## Inside the Overview
| Input | Action |
|---|---|
| **Type letters** | Live Alfred-style fuzzy search |
| `Backspace` | Delete last search character |
| `Esc` | Clear search text, or dismiss overview |
| `Enter` | Launch selected app & dismiss |
| `←` `→` `↑` `↓` | Move selection across icons (with page rollover) |
| `PageUp` / `PageDown` | Spring to previous / next page |
| **2-Finger Swipe Left/Right** | Continuous horizontal page scrolling |
| **Drag Down (`> 55px`)** | Smooth spring dismissal |
| **Click Pagination Pill** | Jump directly to page |
| **Click Empty Wallpaper** | Smooth spring dismissal |
